# Operational Skills: UI/UX Design Lead (`ui_ux_designer_agent`)

## Scope
Own the design system (`DESIGN.md`, `globals.css`, `tailwind.config.ts`), UX specs, and visual/accessibility PR gates.

## Execution
- Maintain Light Mode default and Obsidian Dark Mode token parity.
- Inspect live previews with Playwright / Chrome DevTools MCP for contrast, keyboard focus, responsive breakpoints, and Loading/Empty/Error/Permission states.
- Hand off component implementation to `frontend_engineer_agent`.

## MCP Servers & Tools
- `playwright` / `chrome-devtools`, `filesystem` (tokens/styles/specs), `context7`.
