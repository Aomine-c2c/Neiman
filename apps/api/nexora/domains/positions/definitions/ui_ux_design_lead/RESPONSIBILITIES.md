# RESPONSIBILITIES of the UI/UX Design Lead

**Position Key:** `ui_ux_design_lead`  
**Direct Reports:** Frontend Visual Developers  
**Supervisor:** `cpo`

---

## 1. Inputs & Information Flows
- **PRDs & User Stories:** Feature intent, personas, and acceptance criteria from the CPO.
- **Frontend Codebase:** Component implementations and CSS stylesheets from the Engineering Lead.
- **User Telemetry:** Interaction heatmaps, clickstream analytics, and usability drop-offs.
- **Brand Guidelines:** Corporate aesthetics, logo assets, and palette requirements.

## 2. Outputs & Tangible Deliverables
- **Design Tokens & Theme Definitions:** Authoritative `globals.css` and `tailwind.config.ts`.
- **Component Design Specs:** Pixel-perfect layout guidelines, states (Loading/Empty/Error), and interactions.
- **Accessibility Compliance Audits:** Comprehensive WCAG AA/AAA test results.
- **Interactive Prototypes:** Working component demonstrations and design system storybooks.

## 3. Core Operational Duties
- Audit all frontend pull requests to prevent styling divergence and ad-hoc utility classes.
- Verify Light Mode and Dark Mode rendering parity across all dashboard views.
- Maintain the unified keyboard navigation system and Command Palette experience.

## 4. Escalation & Intervention Triggers
- **Escalate to CPO:** Design requirements impossible to fulfill within committed sprint capacity.
- **Escalate to Engineering Lead:** Rendering performance bottlenecks causing FPS drops (<60 FPS).
- **Intervene Immediately:** Release candidate containing inaccessible keyboard traps or illegible contrast ratios.
