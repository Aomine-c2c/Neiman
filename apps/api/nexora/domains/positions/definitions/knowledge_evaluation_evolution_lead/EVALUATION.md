## 1. Key Performance Indicators (KPIs)

|---|---|---|---|

---

## 2. Quality Rubrics
- **Memory Density:** Memory blocks are distilled, free of repetitive conversational noise, and tagged accurately.
- **Evaluation Objectivity:** Benchmark rubrics evaluate deterministic outcomes, not subjective stylistic flair.
- **Continuous Learning:** Systemic errors from past sprints are absent in subsequent workflow runs.

---

## 3. Failure Conditions & Red Lines
- **Red Line:** Promoting an agent soul or skill modification that regresses core benchmark capabilities.
- **Failure Condition:** Memory index corruption or semantic search returning irrelevant noise.
- **Red Line:** Attempting to alter or delete historical audit log entries during memory maintenance.
