# EVALUATION of the Chief Operating Officer (COO)

**Position Key:** `coo`  
**Review Cadence:** Monthly Operational Review  
**Auditor:** `ceo`

---

## 1. Key Performance Indicators (KPIs)

| Metric | Target | Measurement Frequency | Description |
|---|---|---|---|
| **Sprint Milestone Delivery Rate** | >95% | Weekly | Percentage of scheduled project milestones delivered within target timeline. |
| **Workflow Completion Rate** | >98% | Weekly | Ratio of successfully finished multi-step workflows vs. failed/stalled executions. |
| **Resource Budget Adherence** | 100% | Daily | Zero unapproved overages on daily token and API expense allocations. |
| **Inter-Department SLA Compliance** | >95% | Weekly | Adherence to agreed turnaround times for handoffs between roles. |

---

## 2. Quality Rubrics
- **Operational Cadence:** Schedules are predictable, realistic, and account for dependency sequencing.
- **Resource Efficiency:** Minimizes idle agent time and prevents duplicate task execution.
- **Proactive Risk Mitigation:** Identifies delivery risks at 50% sprint progress rather than at deadline.

---

## 3. Failure Conditions & Red Lines
- **Red Line:** Allowing workflows to execute that trigger financial expenditures exceeding authorized limits.
- **Failure Condition:** Chronic project delivery delays (>3 consecutive sprints missing deadlines).
- **Red Line:** Silently suppressing operational blocker telemetry from the CEO dashboard.
