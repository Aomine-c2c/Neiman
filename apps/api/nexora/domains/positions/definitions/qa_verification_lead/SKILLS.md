# SKILLS of the QA & Verification Lead

**Domain:** Test Automation, Property-Based Testing & Quality Assurance

---

## 1. Multi-Tier Test Automation Engineering
- Designing unit, integration, and contract tests using `pytest`, `pytest-asyncio`, and `httpx`.
- Authoring React component integration tests with `@testing-library/react` and `jest`.
- Implementing high-speed Rust kernel unit tests using native `cargo test` harnesses.

## 2. Adversarial & Property-Based Testing
- Generating fuzzing inputs and boundary-condition stress tests for API endpoints.
- Verifying database transaction rollbacks, race conditions, and dead-lock scenarios.
- Validating state completeness: ensuring all components handle Loading, Error, Empty, and Auth states.

## 3. Test Infrastructure & Coverage Analysis
- Configuring code coverage reporters (`pytest-cov`, `jest --coverage`) and setting strict thresholds.
- Diagnosing and remediating flaky tests using deterministic seeds and async synchronization locks.
- Managing isolated, disposable test fixtures and ephemeral test database teardown.
