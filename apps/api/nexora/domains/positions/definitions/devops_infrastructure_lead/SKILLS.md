# SKILLS of the DevOps & Infrastructure Lead

**Domain:** Container Orchestration, CI/CD Automation & Observability Engineering

---

## 1. Containerization & Runtime Environment Management
- Optimizing multi-stage Docker builds for minimal footprint and rootless execution.
- Managing local and staging container topologies (`docker-compose.yml`, Podman pods).
- Hardening container runtimes: read-only filesystems, dropped capabilities, and resource limits.

## 2. CI/CD Pipeline & Automated Release Engineering
- Designing GitHub Actions workflows and local Makefile build automation targets.
- Implementing blue/green and canary zero-downtime deployment strategies.
- Automating desktop application builds (Tauri Linux AppImage, macOS bundle, Windows binary).

## 3. Observability, Telemetry & Site Reliability Engineering
- Configuring Prometheus metrics exporters, structured logging (`structlog`), and distributed tracing.
- Tuning circuit-breaker trip thresholds and automated failover policies.
- Conducting disaster recovery drills: automated database backups, vector store restores, and failover verification.
