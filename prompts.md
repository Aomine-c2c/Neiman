# NEIMAN — Autonomous Organization Operating System

## Master UI/UX Design Prompt: Living Cognitive Command Center

### Prompt 1 — Build the NEIMAN master control room

### Prompt 2 — Make the central orb genuinely interactive

Refine NEIMAN's Cognitive Core, the main centerpiece of the control room.

Make it the defining visual feature of the product, not a decorative particle sphere.

Create a rich interactive network visualization with multiple layers of depth, particle systems, orbit paths, connected nodes, animated data flows, and a central NEIMAN identity.

Implement these interaction states:

1. **Organization mode:** departments orbit or connect around the core, with workload, agent count, and health indicators.
2. **Workforce mode:** individual agents become visible nodes grouped by function and current activity.
3. **Execution mode:** show tasks moving through workflow stages, with clear paths for successful, delayed, failed, and blocked operations.
4. **Intelligence mode:** show requests being routed between external providers and local models, including fallback paths.
5. **Resource mode:** visualize compute, memory, tokens, network, storage, and budget allocation.
6. **Memory mode:** display relationships among organizational knowledge, decisions, projects, and agents.
7. **Evolution mode:** show candidate improvements, experiments, validation results, and deployment status.

Clicking any node opens a contextual inspector without leaving the control room. Clicking a connection displays the handoff or relationship details. Selecting a node highlights its connected entities and dims unrelated elements.

Add smooth zooming, panning, rotation, focus mode, reset view, a small minimap, and an activity timeline.

Use subtle, purposeful animation. Represent actual system states when data is available; otherwise use clearly marked prototype data.

The visualization must remain responsive, readable, and performant. Design a graceful fallback for devices or browsers that cannot support advanced 3D effects.

Keep the surrounding dashboard compact so the Cognitive Core remains the primary visual focus.

### Prompt 3 — Add the technical depth

Upgrade NEIMAN's control room with the depth of a professional engineering and AI operations console.

Keep the same established brand, central Cognitive Core, and compact top command bar. Do not redesign the application as a conventional admin dashboard.

Improve these areas:

**Workforce:** add agent identities, responsibilities, current tasks, model assignments, autonomy levels, health, permissions, and execution traces. Make every agent inspectable.

**Intelligence Gateway:** display routing rules, provider priorities, fallback chains, task categories, latency, token usage, costs, availability, and model-selection explanations.

**Workflow execution:** provide a live execution graph with step status, retries, dependencies, duration, errors, and the ability to inspect logs and input/output metadata.

**Governance:** show approval requests with the proposed action, requesting agent, policy checks, risk level, affected resources, and consequences. Require explicit confirmation for consequential operations.

**Resource management:** distinguish configured limits, available capacity, current utilization, projected demand, and budget consumption. Support configurable warning thresholds.

**Organizational memory:** show relevant decisions, documents, learned procedures, project context, and knowledge relationships with provenance and access controls.

**Evolution Engine:** show detected weaknesses, proposed improvements, supporting evidence, baseline performance, experiment design, evaluation results, and rollback readiness.

**Telemetry:** create a compact live event stream with filters, severity, source, timestamps, search, and expandable traces.

Use progressive disclosure: show concise summaries first and reveal technical details when an operator selects an item.

Keep labels legible and maintain strong contrast. Use monospaced text for technical identifiers and traces, not for every paragraph.

Include empty, loading, offline, error, and permission-denied states. Ensure every visible action has a defined outcome.

### Prompt 4 — Make the interface configurable on the same page

Implement a configurable workspace system for the NEIMAN control room.

The user should be able to change what appears on the main screen without navigating through a large sidebar or a separate configuration workflow.

Add a workspace-editing mode with:

- Drag-and-drop panel placement.
- Resizable and collapsible panels.
- Show/hide and pin/unpin controls.
- A widget library opened from a contextual plus button.
- Per-widget configuration.
- Saved workspace presets.
- Reset-to-default behavior.
- Layout persistence between sessions where supported.
- Keyboard-accessible alternatives to drag-and-drop.

Available widgets should include Workforce, Cognitive Core, Live Activity, Executive Gate, Intelligence Providers, Resource Overview, Workflow Execution, Organizational Memory, Performance, and Evolution Engine.

When the user selects a node in the Cognitive Core, provide contextual configuration for that node. When the user selects a metric, let them configure thresholds, display style, and visibility. When the user selects a provider, let them inspect and configure routing and fallback policies according to their permissions.

Add three initial presets:

1. **Command:** balanced view for overall organizational operations.
2. **Engineering:** execution graphs, agents, logs, model routing, and technical diagnostics.
3. **Executive:** organizational health, resource allocation, approvals, performance, and evolution proposals.

Preserve NEIMAN's distinctive dark futuristic visual identity. Keep the default workspace uncluttered while allowing advanced users to expose more detail.

Make every customization control functional in the prototype. Do not create inert buttons or a static screenshot disguised as an application.

### Prompt 5 — Final quality and consistency pass

Perform a complete product-design quality pass on the existing NEIMAN control room.

Do not replace the established concept. Preserve the NEIMAN identity, Cognitive Core, dark sci-fi visual language, contextual floating panels, compact top bar, live activity stream, and configurable workspace.

Correct:

- Inconsistent spacing, typography, panel sizing, and alignment.
- Unreadable or excessively small labels.
- Unnecessary empty areas.
- Excessive visual effects that compete with important information.
- Repetitive cards that could be compact summaries.
- Ambiguous status colors and severity indicators.
- Missing loading, empty, offline, failure, and permission states.
- Controls that appear clickable but have no meaningful interaction.
- Poor keyboard accessibility and unclear focus states.
- Layout breakage at common desktop resolutions.

Use a consistent design system for color tokens, typography, spacing, borders, radii, icons, status badges, chart styling, and contextual inspectors.

Keep the visualization beautiful, but ensure operational data remains easy to read and act upon. Use progressive disclosure rather than displaying every technical detail simultaneously.

Ensure the design communicates three things immediately:

1. What NEIMAN is doing.
2. What needs human attention.
3. How the operator can inspect or change the system.

The final result must feel like one cohesive, production-minded AI operating environment rather than separate dashboard widgets assembled on a page.
