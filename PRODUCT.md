# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Enterprise operators, CTOs, engineering leaders, and autonomous organization managers orchestrating multi-agent collectives and sovereign AI infrastructure.

## Product Purpose

NEIMAN OS is an autonomous corporate intelligence operating system. It orchestrates autonomous agent employees, dynamic model routing across frontier/balanced/fast LLM ecosystems, executive councils, decision governance, and architectural self-evolution with strict zero-mock data integrity.

## Positioning

Sovereign enterprise autonomy with air-gapped security, vendor-agnostic multi-provider intelligence routing, rate-limit failovers with 5-hour regeneration cooldowns, and real verifiable execution rather than simulated mock screens.

## Operating Context

- Web Application: Next.js 14 App Router (`apps/web`) operating on ports 3000 (web) and 8000 (FastAPI backend).
- Desktop Wrapper: Tauri (`apps/web/src-tauri`) providing native OS performance, notifications, and system integration.
- Telemetry: Live worker states, dynamic activity feeds, circuit-breaker monitors, and token compression telemetry.

## Capabilities and Constraints

- Dynamic Model Discovery: Periodically fetches active provider models without hardcoded model strings.
- 5-Hour Token Regeneration: Automatic cooldown tracking for rate-limited (429) or quota-depleted (402) model endpoints.
- Strict Type Safety: 0 untyped `any` in business logic; 100% TypeScript compliance.
- Zero Hardcoded Mock Data: Live screens consume backend state; synthetic data restricted to isolated test fixtures.
- State Completeness: Every view explicitly handles Loading, Error, Empty, and Permission states.

## Brand Commitments

- Typography: Inter for clean UI clarity; JetBrains Mono for telemetry, tokens, and code notation.
- Palette: Light Ceramic Alabaster default canvas with high-contrast slate text; obsidian cyber-glow dark mode.
- Voice: Zero polite fluff; dense, actionable, high-velocity technical telemetry.

## Product Principles

1. Truth in Presentation: Every indicator, button, toggle, and metric represents live backend reality.
2. Operator Ergonomics: Keyboard-first navigation (`Cmd/Ctrl + K`), high scanability, rapid workflow control.
3. Sovereign Resilience: Multi-tier fallback hierarchy with air-gapped local model safety net.
4. Token Efficiency: Algorithmic token compression and automatic tier-based model allocation.
